### Added

- **Credential-aware worker list for headless callers**: `GET /api/cluster/workers` now grants a richer view to callers that present a valid credential, without widening the route's auth-exempt gate. A valid local token gets the full admin view; a registry JWT holding an active `cluster_read` grant gets worker detail (capabilities, backends, resources, free VRAM, loaded models) built from an explicit allowlist that withholds every address- and host-identifying field (the worker `url`, its `worker_url` shortcut address, `host_lan_ip`, `hardware`, and each backend's probe `url`) and the admin-only pairing state, so a read-only credential cannot recover a worker's network address; every other caller still gets the stripped anonymous projection, byte-identical to before. `cluster_read` is added to the valid scope vocabulary (#3227).
